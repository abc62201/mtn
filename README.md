# 梦童年游戏管理软件 (MTN)

> 一体化复古游戏资源管理与前端展示平台
> 当前版本：**V3.4.6.11**

MTN（梦童年游戏管理软件）是一款基于 **.NET Framework 4.8** 开发的一体化游戏资源管理平台。
软件采用 **CefSharp** 浏览器内核与 **SQLite** 数据库技术，前端界面通过 **HTML/CSS/JS** 实现深度可定制，
后端逻辑由 **VB.NET** 编写，前后端通过自定义 JS 通信接口双向交互。

它适用于**个人游戏库管理**、**线下游戏体验厅**及**复古游戏收藏**等场景，帮你把散落各处的 ROM、
模拟器、封面与视频统一整理、一键启动，并支持多设备跨平台展示。

---

## 核心特性

- **资源自动化管理**：支持多层级目录扫描，自动识别游戏文件、智能匹配模拟器核心，并支持 IPS 补丁自动应用。
- **全自动智能化入库**：启动后扫描 ROM 文件夹，若服务器存在该游戏样本（按 MD5 匹配），会自动下载对应模拟器、补齐游戏资料并配置启动参数，实现即下即玩。
- **界面可视化编辑**：基于 Web 技术的界面开发框架，内置 **Blockly 图形化低代码编辑器**，拖拽积木即可自定义 UI 主题与交互逻辑，无需手写代码。
- **多模态交互支持**：全面适配键盘、鼠标及主流游戏手柄，支持自定义按键映射；底层混合驱动同时兼容 WinMM 与 SharpDX(DirectInput)。
- **游戏元数据自动补全**：封面、卡带图、视频、简介等多媒体素材统一管理，本地优先、缺失时自动向采样服务器请求。
- **本地 AI 大模型集成**：内置 llama-server 本地大模型部署能力，支持 GPU 卸载层数、上下文长度等参数配置。
- **跨设备 Web 访问**：内置 PHP 服务器，可配置局域网 IP，手机 / 平板等设备可跨平台访问。
- **社区资源共享**：支持游戏采样上传、社区游戏分享、UI 主题与工具下载，构建开放生态。
- **完全开源**：代码完全开放，可按自身需要自由修改与扩展。

## 运行环境

### 硬件环境
- **处理器**：Intel Core i3 2.0GHz 或更高
- **内存**：4GB 及以上
- **硬盘空间**：至少 10GB 可用空间

### 软件环境
- **操作系统**：Windows 10 / Windows 11（32 位 / 64 位）
- **依赖组件**：.NET Framework 4.8、SQLite

## 安装与初始化

1. 双击运行 **`updata.exe`**，软件会自动下载并补全缺失文件，完成更新后自动启动 **`MTN.exe`**。
   - `updata.exe` 同时用于首次安装和后期更新，并通过 **MD5 校验**保证补全因网速损坏的文件。
2. **启动失败处理**：
   - 可多次运行 `updata.exe` 重新更新；
   - 若缺少插件，请安装"如果缺少插件请按照里面的文件"文件夹中的运行环境。

## 快速上手

### 快速分类
1. 打开 ROM 文件夹；
2. 在 ROM 文件夹内新建子文件夹并命名（**务必使用英文或拼音**，部分软件 / 模拟器对路径不支持中文）；
3. 启动软件后，会根据文件夹名称自动添加到对应分类。

### 快速添加游戏
- 打开分类下的 ROM 文件夹，将游戏 ROM 复制进去（例：`rom/fc/rom`）。
- MTN 默认扫描 `.zip` 文件；启动后会自动整理文件夹内所有 `.zip` 为游戏。
- 若服务器已存在该游戏样本（MD5 匹配），会自动下载对应模拟器、补齐资料并配置启动参数，实现全自动管理。

## 基础设置

### 软件启动设置
控制启动视频、开机视频文件夹路径、设置页背景音乐、启动后自动扫描、开机自启、窗口最大化 / 置顶 / 全屏、下载分类归档、下载临时文件夹、PHP 服务器自启、界面语言（简中 / 繁中 / 英文，机翻可在 `msg` 文件修改）、服务器 IP 与端口（默认 `127.0.0.1:80`，开放局域网可改为设备局域网 IP）。

### 本地 AI 大模型
- **前置条件**：在《游戏设置》→《其他下载》→《游戏工具》下载 AI 模型，解压至 `mtn_tool` 文件夹，确认存在 `mtn_tool/llama/llama-server.exe`。
- **GPU 卸载层数（n-gpu-layers）**：`-1` 全部载入显卡（最快，推荐）；显存不足可减小到 20/30 等。
- **上下文长度**：默认 4096 tokens，越大记忆越强但占内存越多。
- **IP 设置**：默认 `127.0.0.1:8080`，通常保持默认。
- 可勾选软件启动时自动运行 AI 服务。

### 模拟器设置
右键空白处呼出全局菜单"添加模拟器"，录入模拟器别名（唯一）、主程序路径、RetroArch 核心文件、版本、图标、简介与展示图。支持背景设置、大/中/小图标密度调整、修改删除、双击试运行。

### 启动参数设置
通过变量替换自定义启动命令，基本结构：`运行的文件 + 启动参数 + 被启动的文件`。常用变量：
`{emu}` `{core}` `{gamefullpath}` `{gamepath}` `{gamefullname}` `{gamename}` `{ipsfile}`。

示例：
- RetroArch：`{emu}+ -L {core} -f +{gamefullpath}`
- Mame：`{emu}+ -rompath {gamepath};roms +{gamefullname}`
- Fbneo：`{emu}+ {gamename} -ips +{ipsfile}`
- PC 游戏 / 直接运行：`{gamefullpath}++`

参数支持命名别名，可添加 / 修改 / 删除模板。

### 下载模拟器
单击选中模拟器图标，系统自动下载至 `temp`、解压到 `emu` 目录，并自动加入"模拟器设置"完成路径关联，无需手动填写。

### 用户登录与注册
登录需输入用户名与密码验证；注册需填写用户名（唯一）、密码、昵称、联系电话、邮箱、QQ（可选），校验通过后即可使用下载服务。

### 下载列表与重复文件
- 下载列表每 30 秒全局刷新一次，避免高频 UI 交互导致卡顿。
- **查看重复文件**：跨目录 MD5 检测，同文件夹内自动去重；不同分类下相同内容仅列出供人工确认，支持"定位 / 删除"。

## 分类设置

### 即时交互设置
表格化可视化配置分类，点击单元格即时弹窗响应。勾选"自动添加模拟器"后，系统比对本地与服务器采样，缺失的模拟器自动静默下载并配置。支持"隐藏 / 恢复"分类；内置默认隐藏分类 `hide_classify`（隐藏游戏）具有系统级保护，不可删除或强制恢复。

### 添加与修改分类
- **基础信息**：排列序号（越小越靠前）、分类标识（对应 ROM 根目录物理文件夹名，唯一，改名会使已配置路径失效）、导航名称（前端展示标题，支持中文）。
- **UI 素材**：导航图标 / 图片、导航背景图、扩展素材（均选填）。
- **运行环境**：选择模拟器 / 核心、添加启动参数、主题选择（必填）。
- **层级管理**：主分类 / 子分类（需选择父级），支持多级目录。

### 设置游戏路径
- **文件类型过滤**：多种后缀用英文分号 `;` 分隔。
- **资源路径映射**：ROM、缩略图、卡带图、视频、简介、IPS 补丁可各设独立路径；以 ROM 文件名（不含扩展名）为基准在同名文件中自动建立关联。

### 扫描设置
- **文件大小阈值**：按 KB 设最小扫描大小，跳过 `.srm`、`.cfg` 等缓存小文件。
- **忽略文件类型（黑名单）**：输入 `*` 为全局忽略，或指定后缀（`;` 分隔）；优先级高于普通规则。

## 游戏设置

- **单游戏手动属性配置**：选中已入库游戏进入专属面板个性化设置。
- **手动新增游戏**：针对自动扫描无法识别的特殊格式，自主指定运行路径入库。
- **游戏采样上传**：一键上传截图、封面、视频，补全服务器采样库，供他人复用。
- **快速查询与定位**：左侧标签聚合筛选 + 右上角关键词实时搜索，毫秒级更新无需刷新。
- **单游戏详细设置**：多媒体素材管理、灵活分类（仅改逻辑索引不动物理文件）、单游戏模拟器优先配置、调试运行验证（先"确定更新"再测试）、资料同步上传、右键快捷定位物理文件、双击 MD5 触发本地优先一致性校验、显式提交机制（不确认即丢弃）。

### 下载资料
- **模拟器游戏下载**：一键启动资源，下载策略同全局，即下即玩。
- **社区游戏分享**：开放网盘 / 网页链接分享，发布者可自主编辑删除。
- **其他下载**：大型游戏、PC 软件、自制 MTN 前端 UI 主题包。
- **修改服务器资料**：像编辑本地游戏一样纠错 / 补全云端条目（禁用运行功能）。
- **上传游戏 / 上传文件**：管理员与高级用户贡献通道，审核上架供全体下载。

## 主题管理

### CefSharp 前端渲染架构
UI 非原生控件，而是 CefSharp 加载的 HTML5/CSS3/JS 网页，后端 VB.NET，通过自定义 JS 通信接口交互。核心目录：
- `myui\index.html`：主界面启动入口，加载 Bootstrap、Blockly 等依赖；
- `set_js / mtn_set.js`：建立 .NET 与前端 JS 双向通信；
- `myui`：用户自定义主题目录，启动时自动扫描加载；
- `set_custom_dict.txt`：键值对配置（窗口激活状态、背景颜色等）。

### 主题 UI 管理
"添加主题"填写主题名称、主入口文件路径（通常 index.html）、缩略图，写入数据库即可选用；不再需要时点击"删除主题"清理。

### 可视化主题编辑器（Blockly）
- **模块化积木编辑**：左栏提供样式(CSS)、结构(HTML)、交互(JS) 三类积木；专属 **VB.NET 通信积木**可拼接调用底层能力（读取游戏列表、启动模拟器、访问文件系统等）。
- **实时编译与预览**：积木实时转译为标准 HTML/CSS/JS，可预览启动独立渲染窗口验证。
- **工程管理**：支持 `.xml`（Blockly 图形化）与 `.mco`（封装 HTML 源码）两种格式打开 / 保存。
- **生成、应用与分享**："生成主题"打包依赖资源（素材需预置入 `file` 文件夹）；"应用主题"部署到 `Html/myui` 并即时生效；"上传主题 / 上传源码"面向社区分享。

## 键盘手柄设置

- **输入设备检测与驱动适配**：双重检测机制——传统 WinMM(`winmm.dll` / `joyGetPosEx`，兼容性好) 与 SharpDX.DirectInput（独占连接、低延迟、线性扳机）。
- **键位映射与信号转换**：图形界面映射按键；位运算解析支持多按键并发组合，格斗搓招不丢指令。
- **资源管理与安全释放**：切换驱动 / 关闭软件时严格释放资源，防止频繁插拔导致崩溃或内存泄漏。

## 个人收藏

将本地游戏目录、可执行程序、网络链接与文档整合到同一视图，实现"一处收藏，多端触达"。
- **智能路径识别**：正则匹配 `http/https` 标记网页链接；本地路径按文件夹 / 文件标记为目录索引或可执行实体。
- **多媒体元数据**：自定义缩略图(JPG/PNG/GIF)、即时屏幕截图作封面、标签与备注（参数化 SQL 安全存储于 SQLite）。
- **前后端实时同步**：SQLiteTransaction 保证写入原子性，完成后通过 CefSharp 的 `EvaluateScriptAsync` 主动推送 `refreshBookmarks()` 刷新前端，毫秒级同步无需手动刷新。

## 隐私说明
