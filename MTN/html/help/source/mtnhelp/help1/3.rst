基础设置-启动参数设置
=====================================================

启动参数设置文件UI路径：html/mtn_set.html和html/set_js/mtn_set_content13.js

一些模拟器启动rom是用过cmd参数来启动游戏的。

主要方式是 模拟器  参数  游戏rom

这里可以提前把模拟器的启动方式进行存储，方面后面分类的时候使用这些参数。

设置规则是用+号进行分割，主要中文和英文的输入发，空格等内容。

可以使用鼠标来点击蓝色的字体来自动生成对应的{gamefullpath}，{core}，{emu}等词缀。

例如：

RetroArc模拟器启动游戏rom时需要使用到运行参数才能启动游戏rom和核心

retroarch[模拟器] -L[参数] 核心 游戏；或者 retroarch -L 核心 -f[全屏参数] 游戏

梦童年参数设置为{emu}+ -L {core} -f +{gamefullpath}

数据库中相关表格。

::

    表emu_args
    字段args 模拟器启动参数
    字段args_name 模拟器启动参数名
