基础设置-设置游戏路径
=====================================================

设置游戏路径文件UI路径：html/mtn_set.html和html/set_js/mtn_set_content22.js

文件类型 手动向rom/分类/对应资源 文件夹添加文件时自动识别文件类型。

路径 各个资源的保存路径多路径可以使用分号（英文输入法）隔开。注意相同的2个文件（md5值）会被删除一个

数据库中相关表格。

::

    表config_path
    字段classify_id 分类id
    字段mtn_path 路径
    字段path_type 扫描类型
    字段path_name 路径名称
    字段rom_size 扫描文件大小
    字段rom_column_name 扫描文件列名（字段名）
    字段file_type 文件类型
    字段file_str  忽略的文件类型
