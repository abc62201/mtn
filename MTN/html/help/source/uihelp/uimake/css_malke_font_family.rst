元素中的字体
=======================================================

.. image:: img/44.png

对元素中的文本字体进行设置。

在 CSS 中使用 font-family 设置字体时，确实依赖于用户系统中是否安装了指定的字体。如果用户的系统中没有安装你指定的字体（例如 "微软雅黑"）
浏览器会尝试使用你提供的备用字体列表中的其他字体，或者最终回退到默认字体。

::

    <style>
    .classname{
    /* 放入其他样式块 */
    font-family:"微软雅黑";
    }
    </style>
