弹性盒子方向对齐
=======================================================

.. image:: img/90.png

flex-direction 属性规定灵活项目的方向。

注意：如果元素不是弹性盒对象的元素，则 flex-direction 属性不起作用。

::

    <style>
    .classname{
    /* 放入其他样式块 */
    justify-content:flex-start;
    }
    </style>
