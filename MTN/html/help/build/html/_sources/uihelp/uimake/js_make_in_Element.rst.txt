.. image:: img/159.png

元素属性 ,对象.属性 这个模块不只是可以获取元素内容。因为他是一个 点 的特点还可以与其他块或文本组合使用。

    
::

    <body>

    <script>
        async function mtn_init(){
        //MTN初始化函数
        await mtn_init();
        var 图层=document.getElementById("图层");
        var 图层中包含的内容=图层.innerHTML;
        }
        }
    </script>

    </body>
