向列表中添加新数据脚本
=======================================================

.. image:: img/136.png

将表2的数据添加到表1里方便合并两个表的数据。

    
::

    <body>

    <script>
        async function mtn_init(){
        //MTN初始化函数
        await mtn_init();
        数据表1.push(...数据表2);
        }
        }
    </script>

    </body>
