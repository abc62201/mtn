固定的背景图像
=======================================================

.. image:: img/21.png

如何指定一个固定的背景图像

在 CSS 中，background-attachment 属性用于定义背景图像的行为，特别是在页面滚动时的处理方式。以下是三种常见的 background-attachment 值及其特点：

1. 背景图片随页面滚动 (scroll)
特点：背景图像会随着页面内容一起滚动。
适用场景：希望背景图像与页面内容同步滚动时使用。

2. 背景图片不随页面滚动 (fixed)
特点：背景图像固定在视口（浏览器窗口）中，不会随页面滚动而移动。即使页面内容滚动，背景图像始终保持在相同位置。
适用场景：创建固定的背景效果，如全屏背景或特定区域的固定背景。

3. 背景图片随元素滚动 (local)
特点：背景图像相对于包含它的元素进行滚动。如果该元素的内容滚动，则背景图像也会随之滚动。
适用场景：适用于带有滚动内容的容器，如带滚动条的 div 元素，希望背景图像与容器内容一起滚动时使用。

::

    <style>
    .classname{
    /* 放入其他样式块 */
   background-attachment:scroll;
    }
    </style>
