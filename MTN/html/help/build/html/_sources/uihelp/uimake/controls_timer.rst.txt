定时器脚本
=======================================================

.. image:: img/129.png

每间隔一定时间后执行函数，单位为毫秒。1000毫秒等于1秒。

    
::

    <body>

    <script>
        async function mtn_init(){
        //MTN初始化函数
        await mtn_init();
        var MTN定时器=setInterval(function(){定时器函数()}, 3000);
        }
    </script>

    </body>
