弹性盒子方向对齐
=======================================================

.. image:: img/92.png

align-items 属性定义flex子项在flex容器的当前行的侧轴（纵轴）方向上的对齐方式。

提示：使用每个弹性对象元素的 align-self 属性可重写 align-items 属性。

::

    <style>
    .classname{
    /* 放入其他样式块 */
    justify-content:flex-start;
    }
    </style>
